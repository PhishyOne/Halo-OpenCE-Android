# Halo v69 — Automatic original title

No normal masthead setup button or confirmation. When the imported game is
available, the launcher is foreground, and no game, repair, recording
consent, or pending invitation is active, automatically start v68's title
preparation. Persist attempted APK version before opening the dedicated
:game process. A successful cache is reused across updates; a canceled or
failed attempt falls back to the existing launcher without an automatic
restart loop. A later version can retry a missing/invalid cache.
First preparation still needs real title rendering/capture (up to one
minute); Cancel remains available on that progress screen. Subsequent
launches play the cached original animation/audio without setup. Nothing
is downloaded; game files and normal game launching are unchanged.
Physical title capture and native CI remain required for acceptance.
