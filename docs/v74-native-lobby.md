# v74 launcher lobby matches

Create or join the same launcher lobby on Wi-Fi or a hotspot. Start reviews the
selected match and names any guests who have Ready turned off. Start Anyway
keeps every member. Each phone checks its local map and acknowledges the
frozen selection. A missing map, player departure, or preparation timeout
returns the group to setup. Use Tools to receive or repair missing maps.

The host and guests start System Link with one-use settings. The guest targets
the host interface it joined and the selected match's advertised name. The
host checks the native seats, observed peer addresses, names, armor colors,
teams, bot counts, map and variant before counting down. Halo's 11-unit name
field shortens long names and adds a suffix when shortened names collide.
Career IDs and saved profiles keep their existing values.

The lobby stays in the launcher process while Halo plays one match. When the
scoreboard closes and the native shell returns, Halo exits to the launcher.
An Android process restart can require recreating or rejoining the lobby.
The first entry follows the playlist's shuffle setting. Automatic rotation
through subsequent entries remains open.

Launcher pregame framing is HLP2. All phones using the shared Lobby need the
updated launcher. Classic System Link still uses gameplay protocol 57.
